为了让您的聊天记录绝不泄露，且永久免费使用顶级 AI，本插件默认连接您电脑本地的 AI 大模型。请按照以下 4 步完成配置（仅需一次）。

第一步：下载并安装 Ollama

Ollama 是目前最强大的本地 AI 运行工具。点击下方按钮前往官网下载，并像安装普通软件一样把它安装到您的电脑上。

前往官网下载 Ollama

第二步：下载 Llama 3.1 翻译模型

安装完 Ollama 后，打开您的电脑终端（Windows 用户请按 Win + R 键，输入 cmd 后回车）。

在弹出的黑框框里，复制并粘贴下面这行命令，然后敲回车：

ollama run llama3.1

此时电脑会自动下载目前最聪明的 Llama 3.1 模型（约 4.7GB）。等待进度条达到 100% 即可。

第三步：核心秘籍 - 配置环境变量 (解决无法连接)

出于安全原因，Ollama 默认不允许浏览器插件直接连接它。我们必须给电脑添加一个“通行证”。

  1. 点击 Windows 左下角开始菜单，搜索 “环境变量”（或 "Environment Variables"）。
  2. 点击 “编辑系统环境变量”，在弹出的窗口右下角点击 “环境变量” 按钮。
  3. 在上方“用户变量”区域，点击 “新建” 按钮。
  4. 变量名输入：OLLAMA_ORIGINS
  5. 变量值输入：* （就是一个星号）
  6. 一路点击“确定”保存所有窗口。

第四步：终极一步 - 重启电脑！

⚠️ 警告：设置完环境变量后，如果不重启电脑，Ollama 是不会读取新设置的通行证的！

请立刻 重启您的电脑。重启后，保持 Ollama 软件在后台运行，您的 WhatsApp 翻译插件就可以完美工作了！

配置完成后，您可以直接关闭此页面。
