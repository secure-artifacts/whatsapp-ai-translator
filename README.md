# WhatsApp AI Translator Pro 🌐🤖

一款专为 WhatsApp 网页版量身打造的 **AI 智能翻译与双向沟通辅助插件**。支持本地离线大模型 (Ollama) 与极速云端 API (Groq)，保障隐私安全的同时提供极高水准的自然口语化翻译。

---

## ✨ 核心功能特性

1. **物理隔离的独立翻译输入框**：
   - 彻底告别对 WhatsApp 原生输入框的破坏性修改。
   - 输入中文后**回车翻译**，显示安全回译与原文对照，**再次回车一键发送**。
2. **🎙️ 麦克风语音实时转写翻译**：
   - 点击插件输入框旁的麦克风即可录音。
   - 搭载 Groq Whisper 极速语音识别，自动将你的普通话转写并翻译为目标外语输出。
3. **📨 对方语音消息一键听写与翻译**：
   - 自动在 WhatsApp 语音消息气泡旁注入绿色翻译按钮。
   - 一键提取音频、精准转录并翻译为中文展示。
4. **✨ 划词气泡极速翻译**：
   - 鼠标随意划选聊天记录中的任意文字，自动浮现翻译小胶囊，点击即可秒级翻译并支持一键复制。
5. **📚 专属记忆词库与在线纠错**：
   - 遇到不符合语境的翻译（如 `Obrigado a Deus`），直接点击 `✏️ 纠错` 即可当场修改并保存。
   - AI 下次再遇到该关键词，将绝对优先使用你的自定义词汇！支持在设置面板在线增删改查。
6. **🛡️ 隐私与数据安全**：
   - 默认支持本地 Ollama (Llama 3.1) 离线运行，聊天数据不经过任何第三方服务器。
   - 零硬编码密钥，所有设置纯本地保存。

## 🚀 安装与使用教程

### 1. 开发者模式安装插件
1. 下载或克隆本项目代码到本地。
2. 打开 Google Chrome 或 Edge 浏览器，访问扩展管理页面：`chrome://extensions/`。
3. 打开右上角的 **「开发者模式 (Developer Mode)」** 开关。
4. 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」**，选择本项目文件夹。
5. 打开 [WhatsApp 网页版](https://web.whatsapp.com/)，按下 `Ctrl + F5` 刷新即可享受完整的 AI 翻译功能！

### 2. 配置本地 AI 或云端 API
- 点击浏览器右上角插件图标打开设置面板。
- 点击 **📖 新手必看：本地 AI 免费配置教程** 查看 Ollama 一键配置。
- 若需使用语音转写功能，可填入免费申请的 **Groq API Key**。

## 如何发布新版本

本项目使用 GitHub Actions 自动构建和发布。每次发布新版本只需要创建一个 Git Tag 并推送即可。

### 发布步骤

#### 1. 确保代码已提交并推送

在发布之前，确保你的所有代码改动已经提交并推送到 GitHub：

```bash
# 查看当前状态
git status

# 添加所有改动
git add .

# 提交改动（把"你的改动说明"替换成实际的描述）
git commit -m "你的改动说明"

# 推送到 GitHub
git push origin main
```

#### 2. 创建版本 Tag

Git Tag 是一个版本标记，用于标识发布的版本号。版本号格式为 `v主版本.次版本.修订版本`，例如 `v1.0.0`、`v1.0.1`、`v1.1.0`、`v2.0.0`。

```bash
# 创建一个新的版本 tag（将 v1.0.1 替换为你想要的版本号）
git tag -a v1.0.1 -m "Release version 1.0.1"
```

#### 3. 推送 Tag 触发自动构建

```bash
# 推送 tag 到 GitHub（这会自动触发 CI 构建）
git push origin v1.0.1
```

推送后，GitHub Actions 会自动执行以下操作：
1. 构建项目并将核心文件打包为 `.zip`
2. 生成符合 SLSA v1.0 标准的安全构建签名证明（Attestation）
3. 在 GitHub 仓库的 Releases 页面自动生成发布版本与下载链接
